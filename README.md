## 玩法

- **全屏自由移动**
- 方块上的数字 **= 基础耐久，也 = 打掉得几分**；前期只有 **1~30**，30 秒后逐步开放到 **1~100**；1~49 普通方块每枪 -1，50~100 大块每次至少 -10，打到 0 才得分
- 方块从天而降，**活得越久，掉得越快**（右上角显示倍率，最高 ×2.6）
- **红色危险物打不掉**（子弹会被弹开），只能躲
- **危机模式**：存活越久触发率越高（10% → 30%），持续 10 秒；炸弹和危险物变多，分值方块仍会出现
- **护甲方块**：部分分值方块随机获得 **10%~30% 免伤**，存活越久出现概率越高（初始 5%，120 秒升到 60% 上限）
- **3 条生命**：任何东西撞到你掉一条命，掉光结束；受伤后 1.6 秒无敌闪烁
- 金色奖励目标：第一次在 **30 秒**出现，之后每次再多等 **10 秒**（40、50、60…），5 滴血，打掉 **+20**
- **武器升级**：普通武器最高 Lv10；第 10 秒第一次出现，之后间隔每次 +5 秒；每次随机给 1~3 张卡，选一张
- **特殊攻击**：激光（15）、火球（10）、炮弹（5）最高 Lv5，每轮开火按等级概率触发
- **恢复模块 / 恢复光束**：绿色 `+` 模块打掉回 1 滴血；恢复光束最高 Lv3，触发率 10% → 20%，触发回 1 滴血
- **连击**：2 秒内连续击杀，分数 ×2 / ×3 / ×4（封顶）；超时或挨打就断
- 全程有音效：射击、命中、击碎、受伤、升级、奖励、结束

## 武器升级

按**时间**出现，不是按分数：第 10 秒第一次，之后每次间隔 +5 秒。

| 第几次 | 出现时间 | 当时间隔 |
| --- | --- | --- |
| 1 | 0:10 | 10s |
| 2 | 0:25 | 15s |
| 3 | 0:45 | 20s |
| 4 | 1:10 | 25s |
| 5 | 1:40 | 30s |
| 6 | 2:15 | 35s |

每次弹出时**随机给 1~3 张卡**（不会超过还能升的模块数），选一张。等级只在**本局**有效，重开归零。

| 模块 | 等级 | 效果 |
| --- | --- | --- |
| 射速 | Lv1 → Lv10 | 射击间隔 0.120s → 0.063s（每秒约 8 → 16 发） |
| 弹道 | Lv1 → Lv10 | 一次打出 1 → 10 颗子弹，左右散开 |
| 移速 | Lv1 → Lv10 | 移动速度 540 → 900 px/秒 |

满级卡片会变灰、标注“已满级”，也仍可能出现在本次选择中；选择它只会提示“已满级”，不会消耗这次升级。全部满级后会弹一次“武器已满级”提示，之后不再打断游戏。

### 特殊攻击

升级卡里会出现三种攻击型特殊武器（最高 Lv5）和一种恢复光束（最高 Lv3）。解锁后**每轮普通开火按概率触发**，等级越高触发概率越高。

| 特殊攻击 | 伤害 | 触发概率 Lv1 → 满级 | 特点 |
| --- | --- | --- | --- |
| 激光 | 15 | 2% → 6% | 瞬发，竖向穿透路径上的所有目标 |
| 火球 | 10 | 3% → 7% | 命中后爆炸，范围伤害 |
| 炮弹 | 5 | 4% → 8% | 触发率最高，小范围爆炸 |
| 恢复光束 | — | 10% → 20%（Lv1 → Lv3） | 触发恢复 1 滴血，最高只有 Lv3 |

所有已解锁的特殊模块都会独立判定，可能同一次开火同时触发多种。特殊攻击的等级和普通升级一样，只在**本局**有效，重开归零。

### 回血模块

绿色 `+` 模块从天上落下，打掉恢复 **1 滴血**，不会伤害玩家。

- 普通模式约 6% 概率出现
- 危机模式约 18% 概率出现
- 满血时不会浪费回血判定

### 危机模式

每隔 15 秒检查一次，存活越久触发概率越高：

| 存活时间 | 触发概率 |
| --- | --- |
| 0 秒 | 10% |
| 60 秒 | 约 20% |
| 120 秒 | 30% 上限 |

危机持续 10 秒。期间每一波都会：

- 生成至少 1 个分值方块，保证仍有分可拿
- 生成至少 1 个红色危险物，65% 概率再多 1 个
- 55% 概率生成 1 个炸弹
- 生成间隔比普通模式更短

炸弹是危机专属模块：3 点耐久，打爆或撞到玩家都会爆炸；爆炸会清除周围一圈红色危险物，但撞到玩家仍然扣一条命。

## 声音是怎么来的

没有任何音频文件：全部用 WebAudio 现场合成（`tone()` 振荡器 + `noise()` 白噪声）。

浏览器有自动播放限制，所以音频是在你**第一次点击/按键开局时**才解锁的——如果一开始没声音，点一下画面就有了。

## 想改就改这几处

1. **升级太快 / 太慢** → `CFG.upgradeFirst`（第一次几秒出现，默认 10）、`CFG.upgradeStep`（每次间隔加几秒，默认 5）。
2. **调某个模块的强度 / 等级上限** → `UPGRADES.rate.values` 这类数组；数组长度就是最高等级，`max` 要同步改。
3. **调特殊攻击** → `SPECIALS.laser.damage` 改伤害，`SPECIALS.laser.chance` 改 Lv1~Lv5 触发概率；火球、炮弹同理。
4. **调恢复光束** → `SPECIALS.recovery.chance`（Lv1~Lv3 的 10% / 15% / 20%），`CFG.healModuleChance` / `CFG.crisisHealChance` 调回血模块概率。
5. **调危机模式** → `CFG.crisisFirstCheck`（第一次检查）、`CFG.crisisCheckGap`（检查间隔）、`CFG.crisisDuration`（持续时间）、`CFG.crisisChanceMin` / `CFG.crisisChanceMax`（10%~30%）、`CFG.crisisChanceRamp`（多少秒达到上限）、`CFG.crisisBombChance`（炸弹概率）。
6. **调护甲** → `CFG.armorStartChance`（初始出现概率）、`CFG.armorMaxChance`（上限）、`CFG.armorRamp`（多少秒达到上限）、`CFG.armorMin` / `CFG.armorMax`（免伤范围）。
7. **太难** → `CFG.speedCap` 调小、`CFG.lives` 调大、`CFG.spawnMin` 调大。
8. **奖励来得太晚 / 太早** → `CFG.bonusInterval` 是第一次的间隔（默认 30 秒），`CFG.bonusStep` 是每次增加的秒数（默认 10）。
9. **没危险物 / 太危险** → `CFG.hazardChance`（0 = 关掉，0.4 = 到处都是）。
10. **想让方块只挨一枪就碎** → `spawnBlock()` 里把 `hp: value` 改成 `hp: 1`（分数仍然是分值）。
11. **声音太吵** → 改 `SFX` 里各个 `vol`，射击是 `0.016`，最吵的是受伤 `0.11`。
12. **连击窗口 / 上限** → `COMBO_WINDOW`（默认 2 秒）、`COMBO_MAX`（默认 ×4）。
13. **想取消"挨打断连击"** → 删掉 `hurt()` 里的 `comboHits = 0; comboTimer = 0;` 两行。
14. **调分值范围 / 大块规则** → `CFG.scoreStartMax`（前期上限，默认 30）、`CFG.scoreRampDelay`（前多少秒保持 30）、`CFG.scoreRamp`（多少秒升到 100）、`CFG.scoreMax`（默认 100）、`CFG.bigBlockMin`（默认 50）、`CFG.bigBlockStep`（默认每次至少扣 10）。

## 两个新手最容易踩的坑

- **别用 `setTimeout` / `setInterval` 做游戏循环**，会漂移、会卡、切标签页会失控。用 `requestAnimationFrame` + `dt`。
- **所有位移都要乘 `dt`**（`x += speed * dt`），否则 60Hz 和 144Hz 屏幕上速度不一样。
